
…plus a `FAQPage` block generated from the seven questions in
`src/content/convx.ts`, which is what earns the expandable FAQ rows in the
search result.

`softwareVersion` and `downloadUrl` update themselves from the GitHub
Releases API every hour — no manual edit when you cut v1.5.

**`aggregateRating` is deliberately omitted.** Google requires ratings to come
from a real, user-visible review system on the page. Fabricated or
GitHub-star-derived ratings are a manual-action risk. Add it only if you ship
a genuine review widget.

## 3. Performance notes

Already handled:

- **Images** — all screenshots go through `next/image`. Netlify's Next runtime
  serves them via the Netlify Image CDN as WebP/AVIF at the requested size, so
  the 28 MB of source PNGs never reach a visitor. Every image carries explicit
  `width`/`height`, so there is no CLS.
- **LCP** — only the two hero phones use `priority`; everything else lazy-loads.
- **Fonts** — Fredoka (`next/font/google`) and Satoshi (`next/font/local`) are
  self-hosted and inlined by Next with `display: swap`. No render-blocking
  third-party font request, so no preconnect needed.
- **GitHub API** — fetched server-side with `revalidate: 3600`. Visitors never
  make the call, and the rate limit is never approached.
- **`dns-prefetch`** for `github.com` and `objects.githubusercontent.com` so the
  APK download starts faster on click.
- **Analytics** — GA4 loads with `strategy="afterInteractive"`, off the critical
  path, and renders nothing unless `NEXT_PUBLIC_GA_ID` is set.

Worth watching:

- The screenshot rail pins on desktop (`ScrollTrigger`). If Lighthouse flags
  long tasks on low-end mobile, note the pin is already disabled below 1024px.
- Source PNGs live in both `src/convx_images/` and `public/convx/`. Deleting the
  `src/` copy halves repo weight; nothing imports it.

## 4. Content & backlinks

### dev.to / Medium post outline

**Title:** "I rebuilt Apple's Liquid Glass in Jetpack Compose — here's what it
actually takes"

1. Why stock Material blur isn't Liquid Glass (translucency vs. real refraction)
2. Capturing a backdrop in Compose — `rememberLayerBackdrop()` and
   `Modifier.layerBackdrop()`
3. Sampling it: `drawBackdrop()`, blur radius, vibrancy and lens distortion
4. Making it cheap — what killed the frame rate and what fixed it (idle redraw,
   glass transition cost, off-main sorting)
5. Shipping it: Media3, Room and the bits of the player the glass sits on top of

Link naturally to `https://cosmic-taser.netlify.app/convx` in the intro and the
closing line. One do-follow from dev.to plus the Reddit/HN crossposts is worth
more than any on-page tweak left.
